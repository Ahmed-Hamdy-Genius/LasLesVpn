# LaslesVPN — Landing Page

Landing page for **LaslesVPN**, a fictional VPN product, built as a
hands-on assignment on the front-end fundamentals roadmap at
[Almdrasa Platform](https://almdrasa.com/).

Built with semantic HTML and CSS (authored in SCSS).
No frameworks, no JavaScript.

## Live site

<https://ahmed-hamdy-genius.github.io/LasLesVpn>

## Sections

Navigation · Hero · Stats · Features · Pricing (Free / Standard / Premium)
· Global map · Testimonials · Subscribe · Footer

## Stack

- Semantic HTML5 (`header`, `nav`, `main`, `section`, `footer`)
- Layout: Flexbox + CSS Grid
- Styles authored in SCSS (`styles/style.scss`), compiled to `style.css`
- Rubik from Google Fonts, brand accent `#F53838`

## File map

    index.html      — markup
    styles/         — SCSS source + compiled CSS
    assets/         — images and icons
